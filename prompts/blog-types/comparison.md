# Blog type: Comparison

Example titles: "Asana vs Trello: Which Project Tool Fits Your Team? (2026)", "Spreadsheets vs Payroll Software"

## Suggest this type when
The keyword contains vs, versus, compared, comparison, or two named products or approaches.

## Confirm before research
- The two (or three) options being compared
- Whether one is the company's own product (changes tone: confident, still fair)

## Research must fetch
For each option: features, pricing, limits, integrations, ratings, ideal user, from its own pages. Store each page.

## Default length
2,000 to 3,000 words.

## Outline template

```
[Intro: the decision the reader is trying to make]
H2: [A] vs [B] at a Glance   [comparison table: criterion | A | B]
H2: What Is [A]? / What Is [B]?
H2: [Criterion 1]: How [A] and [B] Compare ... (5 to 7 criteria)
H2: Which Should You Choose? [Who should pick A, who should pick B]
H2: Frequently Asked Questions
```

## Rules
- Each criterion ends with a plain verdict for that criterion.
- The final recommendation names who each option suits. Never declare a universal winner.
